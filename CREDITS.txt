The optional named themes use the approved numerical palette values and names from the user-owned Petal Key palette catalog; Petal Reader shares the 16 color palettes. Dart implements its own theme rendering. Standard Light and Standard Dark follow the Petal Key neutral additions.
Work/synthetic/Artwork-Test.mp3 is generated sine-wave audio with generated test artwork. Neither it nor the test JPEG is bundled in the APK.
app/src/test/resources/artwork-tone.mp3 is a copy of that synthetic fixture for source-only parser regression tests. It is not bundled in the APK.
Work/synthetic/Tagged-Test.mp3 is a copy of that generated tone with synthetic ID3 title and author tags; it is test-only and not bundled.
app/src/test/resources/chapter-tone.m4a is a generated six-second AAC sine wave with generated chpl chapter markers. It is included only in the source test suite and not in the APK. GStreamer was used to generate the synthetic AAC base file; its binaries are not bundled.
