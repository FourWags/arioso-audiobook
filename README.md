# Dart

Dart is an offline Android audiobook player without app network access. It plays on-device audio files that you choose with Android's document picker; the app contains no book or audio content. Its code and simple vector icon were written for this project and are licensed under MIT. No Petal Voice source, artwork, fonts, or media are included.

The default interface follows Petal Key's warm stone, cream card, and mauve control style. Use Theme in the header to choose among Dart's Warm Stone, the 16 named color palettes shared by Petal Key and Petal Reader, and Standard Light or Standard Dark. The selected theme stays in private app preferences. Dart uses its own rendering code and icon; no other app's fonts, drawables, source files, or bundled media are copied. Changing themes pauses playback and restores the selected title and place.

## Features

- Add audio files or scan a folder through Android's on-device document picker. Dart asks for local files and rejects other provider authorities, including cloud storage providers. It keeps document grants and settings in private preferences and book metadata, bookmarks, and progress in a private transactional SQLite database. Existing preference libraries migrate without erasing the legacy copy. It never copies or deletes original audio. Folder scans are bounded to 500 files and require confirmation before adding listings.
- Tap a title to load it. Play/pause, seek, choose a back/forward skip pair, choose playback speed from 0.75× to 3.0× with unchanged pitch, and resume after restart. Add up to 100 named bookmarks per book. A local listen-next queue advances automatically after a file completes.
- Set a 5, 15, 30, or 60 minute sleep timer, choose a 15-second fade, or stop at the end of the current chapter. The playback service keeps an active timer under lock; pausing cancels it.
- For seekable M4B/M4A/MP4 files, Dart reads supported `moov/udta/chpl` markers and QuickTime text chapter tracks linked from an audio track with bounded local parsers. Search chapter titles, jump from the chapter list, or use previous/next chapter. The list stays in a small memory cache and is read again after restart. Unsupported chapter formats leave audio playable without a chapter list.
- The selected title and place return after rotation or reopening Dart. A foreground playback service keeps audio playing while the phone is locked or another app is open. Its private media notification and Android media session offer pause, seek, and skip controls. Pausing releases foreground service status; a stopped, unbound service releases the decoder. Dart requests audio focus before playback and pauses when focus is lost.
- The library has searchable Authors, Series, and Books grids. Author and series cards stack up to three representative covers. Long press a book to edit title, author, author sort name/aliases, series/order, narrator, edition, custom shelf tags, and optional multipart title/order. Numbered books appear in numeric order, including prequels and fractional positions. Multipart files can appear as one title and play in part order. Filename patterns can suggest a series and number, which remain editable. Search and shelf filters work entirely on device.
- Dart displays supported embedded artwork or a user-selected local cover. It keeps decoded thumbnails in a bounded memory cache and uses a generated title cover when art is absent or unsupported. No artwork is copied into the APK or saved as a separate file.
- Dart reads small MP3 ID3 and M4A/M4B MP4 cover payloads with a bounded local reader before decoding them. Unsupported or oversized artwork falls back to the generated cover. On low-memory signals Dart drops its decoded artwork cache.
- Book cards show saved listening progress or Finished after playback completes. Progress is calculated from the last saved position and the duration reported by the player.
- On import, Dart reads supported embedded title and author tags in the background. For seekable MP4/M4B/M4A files it also reads bounded iTunes freeform `SERIES` and numeric `PART` fields when present. Unsupported or missing tags leave the filename and editable details in place. Manual edits take precedence if they happen before extraction finishes. Series and series order remain editable manually.
- If a provider revokes access, a file disappears, or audio is invalid, Dart shows an unavailable state and leaves other entries intact. Relink a moved file through the local picker to retain its listing and progress.
- Export and import a bounded local JSON metadata backup through Android Files. It contains no audio; keep the original media available separately. Android automatic backup remains disabled.

A catalog-only export still contains titles, file links, covers, and other library details in plain text at the on-device location you choose. Fingerprint matches are suggestions: recheck the current files before removing a listing. Deterministic malformed-media tests now exercise the bounded chapter, series-tag, and artwork parsers.

Playback now saves speed and optional voice pitch per book. Bookmarks can be searched by note, queues can be saved as presets, chapter sleep can stop after two or three chapters, and chapter labels can be corrected locally. Completion history and a Continue Listening row stay on device. The cover grid adapts to wider screens, and hardware keyboards can focus search with Ctrl+F. File-open failures show a plain-language recovery hint.

Playback pauses when Android reports that headphones or another audio route disconnected. Chapter-count sleep targets are bounded by the final chapter or file end. Other chapter-track formats and physical-device testing are future work. This is a personal preview. Petal Voice's optional Audiobookshelf account and download features are outside Dart's local-file design.

Android may return a new document URI if a file is moved and selected again. Use Relink on-device file on the existing listing to preserve its metadata and progress. Adding the moved file as a new book keeps both entries for review.

## Privacy and content rights

Dart requests the two Android media playback foreground service permissions so listening can continue under lock. It requests no Internet, microphone, media-library, broad storage, or notification runtime permission. Its only media input is a user-selected on-device document URI from Android's Files, Downloads, or Media provider. Its listing and playback positions stay on the device with Android backup disabled. The picker asks for local files; Dart checks provider authorities again before import and playback, including for older saved listings. This does not attest that a modified or unusual system provider never obtains data remotely. A selected file remains governed by its own copyright or license; Dart's MIT license covers only Dart's code and icon. Do not redistribute someone else's audiobook with the app without permission.

Background media readers use the application context and weak references to the screen. Pending cover targets are capped, the decoded cover cache is limited to 8 MiB, and screen destruction clears UI callbacks and in-memory caches. The separate playback service owns the decoder and releases it when stopped and unbound. Dart's MP3/MP4 cover reader skips payloads over 2 MiB before allocating them. A provider's native file and metadata implementation remains outside Dart's memory controls.
