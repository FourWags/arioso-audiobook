# Dart

Offline audiobook player for user-selected local files. The app does not request Internet access or bundle audiobooks.

The verified personal-preview APK and complete corresponding source ZIP are available in [Releases](https://github.com/FourWags/dart-audiobook/releases). See each release's verification report and checksums for the exact tests and limits.
