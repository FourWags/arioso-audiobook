# Arioso 0.1.0-preview.40 — Turning Page icon

The default launcher icon now shows a turning page and sound waves. Adaptive and themed monochrome versions are included. The library's empty state offers a folder-first import and starts Android's picker at device storage.

This is a personal Preview candidate. The signed APK retains Arioso's package and signing identity. Host tests and Android 36 emulator upgrade/launch checks passed; release lint has 0 errors and 25 warnings. Phone folder navigation, actual audiobook playback, Bluetooth, live accessibility, and performance remain untested for this candidate. This candidate has not been published or installed on the user's phone.
