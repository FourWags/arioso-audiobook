# Arioso 0.1.0-preview.44 — Easier Folder Import

Adding books now offers a choice to browse all locations in Android Files, start at phone storage, or choose individual audio files. The compact rail has a visible Add audiobooks action. If a folder provider fails or a scan reaches its limit, Arioso leaves the library unchanged instead of offering a partial import. The library and player share a more consistent editorial heading style. The Preview.43 direct standalone-book path remains.

This is a personal Preview distributed through GitHub Latest for Obtainium testing. The Android package, offline permission set, and dedicated signing identity remain unchanged. See CHECKS.txt for exact checks and limitations. Publication as Latest does not establish Google Play or production readiness.

The phone app is not updated as part of preparing this release. The reported Pixel Downloads-only picker behavior, personal audiobook playback, live accessibility, Bluetooth, Android Auto, battery and performance behavior, Google Play qualification, and commercial sale readiness remain unqualified for this build.

Verification: 60 freshly executed unit tests, debug/release builds and release lint passed (0 errors, 25 warnings). The exact signed APK kept the dedicated signer and offline permission set, upgraded signed Preview.43 on a disposable Android 36 emulator, and imported one synthetic M4A from Audiobooks through Android Files. No personal phone upgrade, Pixel picker retest, live accessibility, Bluetooth, Android Auto, or long-playback/battery test was completed for this build.
