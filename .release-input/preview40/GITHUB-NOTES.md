# Arioso 0.1.0-preview.40 — Turning Page

The default launcher icon shows a turning page with sound waves, including adaptive and themed monochrome versions. The library's empty state now offers folder-first import and starts Android's picker at device storage.

This is a personal Preview, published as GitHub Latest for Obtainium. The package and signing identity are unchanged. Sixty host tests passed; release lint reported 0 errors and 25 warnings. The exact signed APK passed an in-place update from preview.39 and a launch check on an isolated Android 36 emulator. The APK's permission set remains limited to media foreground services; the packaged notices and commercial input audit passed.

Phone folder navigation, live audiobook playback, Bluetooth, accessibility, performance, battery behavior, Google Play readiness, and commercial sale readiness are unqualified for this candidate. The phone has not been updated as part of this release.
