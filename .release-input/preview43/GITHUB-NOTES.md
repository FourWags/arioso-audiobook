# Arioso 0.1.0-preview.43 — Direct Standalone Books

An author's page now lists standalone titles as books alongside any real series. Tap the author, then tap a standalone title to open it; series still opens its books in order. The author page shows a scoped book count and keeps Authors highlighted in the rail. Global Series and Books browsing remain available.

This is a personal Preview distributed through GitHub Latest for Obtainium testing. The Android package, offline permission set, and dedicated signing identity remain unchanged. See CHECKS.txt for exact checks and limitations. Publication as Latest does not establish Google Play or production readiness.

The phone app is not updated as part of preparing this release. Personal audiobook playback, live accessibility, Bluetooth, Android Auto, battery and performance behavior, Google Play qualification, and commercial sale readiness remain unqualified for this build.

Verification: 60 unit tests, release build and lint passed; lint reported 25 warnings and no errors. A disposable Android 36 emulator passed the author-to-standalone path with three synthetic books, confirmed real series navigation, and completed a signed 42→43 upgrade. No physical phone upgrade, personal audiobook playback, live TalkBack, Bluetooth, Android Auto, or battery/performance test was completed for this build.
