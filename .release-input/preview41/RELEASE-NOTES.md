# Arioso 0.1.0-preview.41 — Library Rail

A compact side rail now opens Home, Authors, Series, Books, listening history, and appearance. The library keeps its A–Z author index, series-order browsing, and mini-player. Library Rail is the default on new installs; existing layout choices remain saved and can be changed in Appearance.

This is a personal Preview, published as GitHub Latest for Obtainium. The Android package and dedicated signing identity are unchanged. Sixty freshly run unit tests, offline packaging checks, and a signed Preview.40 to Preview.41 upgrade on an isolated Android 36 emulator passed. Release lint had zero errors and 25 warnings. The rail also passed basic navigation checks, with tab fallback at 200% font and in landscape.

The user's signed Arioso was not updated during this release preparation. Personal audiobook playback, live accessibility, Bluetooth, Android Auto, battery and performance behavior, Google Play qualification, and commercial sale readiness remain unqualified for this build.
